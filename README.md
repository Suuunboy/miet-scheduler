# miet-scheduler

Утилита, которая загружает учебное расписание группы с [miet.ru/schedule](https://www.miet.ru/schedule)
и сохраняет его в файл iCalendar (`.ics`). Такой файл можно импортировать в Google Calendar,
Apple Calendar, Outlook и другие календари.

Каждое занятие становится отдельным событием. В событии указаны:

- название и тип занятия;
- преподаватель и аудитория;
- номер пары и тип недели;
- пометки о дистанционном формате и занятиях по подгруппам.

## Как устроено расписание МИЭТ

Расписание чередуется по четырёхнедельному циклу:

| `DayNumber` | Неделя          |
|-------------|-----------------|
| 0           | 1-й числитель   |
| 1           | 1-й знаменатель |
| 2           | 2-й числитель   |
| 3           | 2-й знаменатель |

`Day` (1–6) — день недели, с понедельника по субботу.

Неделя, на которую приходится первый рабочий день семестра, считается 1-м числителем.

Границы семестров:

- **осенний**: с 1 сентября по 31 декабря;
- **весенний**: с 1 февраля по 31 мая.

## Требования

- Python 3.14+
- [uv](https://docs.astral.sh/uv/) (рекомендуется) или pip

## Установка

```bash
git clone https://github.com/<user>/miet-scheduler.git
cd miet-scheduler
uv sync
```

## Использование

```bash
uv run miet-scheduler --group П-11
```

Календарь сохраняется в файл `П-11.ics` в текущей директории. Название группы можно
писать в любом регистре. Если такой группы нет, утилита предложит похожие названия.

Ещё примеры:

```bash
# Список всех групп
uv run miet-scheduler --list-groups

# Свой путь к файлу и цвета
uv run miet-scheduler -g П-11 -o schedule.ics --color gray --color-map "Лаб=green" --color-map "Информатика=blue"

# Семестр начался не в стандартную дату
uv run miet-scheduler -g П-11 --start 2026-09-07
```

| Параметр | Описание |
|----------|----------|
| `-g`, `--group` | Название группы. |
| `--list-groups` | Вывести список всех групп. |
| `-o`, `--output` | Путь к `.ics`-файлу. По умолчанию `<группа>.ics`. |
| `--color` | Цвет всех событий: имя цвета CSS3 (`gray`, `blue`, `green`…). По умолчанию `gray`. |
| `--color-map КЛЮЧ=ЦВЕТ` | Цвет для отдельного предмета (`Информатика`), полного названия (`Информатика [Лек]`) или типа занятия (`Лек`, `Пр`, `Лаб`, `Конс`). Можно указать несколько раз. |
| `--start`, `--end` | Границы семестра в формате `ГГГГ-ММ-ДД`. От даты начала отсчитывается цикл недель. |

Утилиту также можно запустить как модуль: `python -m miet_scheduler`.

### Цвета

Цвета записываются в свойство `COLOR` (RFC 7986). Apple Calendar и Thunderbird его
поддерживают. Google Calendar при импорте `.ics` цвета событий игнорирует.

### Повторный импорт

У каждого события постоянный `UID`. Поэтому при повторном импорте обновлённого
расписания в тот же календарь события заменяются, а не дублируются. Это работает
в клиентах, которые учитывают `UID`.

## Источник данных

Утилита использует открытые эндпоинты сайта МИЭТ:

- `POST https://www.miet.ru/schedule/groups` — список групп;
- `GET https://www.miet.ru/schedule/data?group=<группа>` — расписание группы.

Это неофициальный проект, он никак не связан с НИУ МИЭТ.
